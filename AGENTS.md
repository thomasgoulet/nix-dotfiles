# Repository

This repository lives at `~/.config` and serves two purposes simultaneously: it is a Nix flake (under `~/.config/flake/`) that declaratively manages the entire system, and it is a standard XDG configuration directory whose files are tracked in git. Some configuration files (for example `starship.toml`) are generated by Home Manager and symlinked here; other files are plain files committed directly. The `.gitignore` uses an opt-in strategy; everything is ignored by default, with specific paths explicitly tracked. This prevents accidentally committing secrets or files generated by Nix.

# Flake Structure

The file `flake/flake.nix` is the entry point.

[`den`](https://den.denful.dev/reference/glossary/) allows composition of nix aspects for the different hosts and users.
Each aspect can provide attributes that will be with the other aspects;
- `includes` is a list of required aspects for this aspect to function properly.
- `nixos` is an operating system module.
- `user` is for user specific configurations.
- `homeManager` is a home manager module.

[`import-tree`](https://import-tree.denful.dev/reference/api/) removes import clutter and automatically imports new files. Folders prefixed with a `_` are ignored by `import-tree` unless explicitly targeted.

[`flake-parts`](https://flake.parts/getting-started.html) helps create the flake for each system.

## Module Layout

```
flake/
├── flake.nix
├── flake.lock
└── modules/
    ├── aspects/ # Shared den aspects to be re-used
    ├── nixos/ # Hosts
    └── users/ # Users
```
